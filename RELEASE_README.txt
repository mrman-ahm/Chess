SIXTY-FOUR
==========

To play:

1. Keep every file and folder together.
2. Double-click sixty-four.exe.

The game creates personal settings in data\config and saved matches in
data\saves. No installation is required.

Requirements:
- Windows 10 or Windows 11, 64-bit
- A processor with AVX2 support for the bundled Stockfish engine

If Stockfish cannot run, the game falls back to its basic built-in move
selection instead of crashing.

Created by Muhammad Ahmad as a student game-development project.
